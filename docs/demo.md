# Optional sample-data walkthrough

This walkthrough requires `SEED_DEMO_DATA=true` before first database startup. Sample accounts and records are disabled by default and are for evaluation only.

## Learner

1. Open the app and sign in as `learner@demo.gov.in` with `learn1234`.
2. Explore the dashboard and competency page. The account and its records are synthetic.
3. Start a skills check, answer each question, and submit. The result shows feedback, source references, updated evidence, gaps, and next courses.
4. Open Learning, add a recommended course to the path, then mark it complete to demonstrate progress and competency evidence updates.
5. Ask the assistant about sampling or data quality. The answer shows local source names and page references. Ask about a topic absent from the corpus to see the assistant abstain.

## Trainer

Sign out, then sign in as `trainer@demo.gov.in` with `learn1234`. In Trainer Studio, upload a text-based PDF, DOCX, PPTX, TXT, or Markdown file (up to 10 MB), select a competency, and add it. Ask for a source-based draft or create a question manually. The queue retains drafts until approved; publish one to make it eligible for learner assessments.

## System admin

Sign in as `admin@demo.gov.in` with `learn1234`. Review aggregate dashboards and recent local audit events. The dashboard includes a synthetic training-demand scenario that is explicitly not a forecast. Use Framework Administration to add a competency, create another job role, and map a required level. Analytics are synthetic and are not operational measurements.

## Constraints

The iGOT and NSSTA/TPAC catalogue entries are mock-labelled seed data. No external account or content is contacted. Do not use real personal, confidential, or official records.
